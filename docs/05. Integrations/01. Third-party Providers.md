# Third-party Providers

Sashakt can connect to **external providers** — for example, a partner organization's API that supplies questions, certifies candidates, or syncs results.

> _📷 Screenshot placeholder: Provider configuration page_

## What providers are for

Providers are useful when your organization works with an external system that:

- Pushes candidate lists into Sashakt
- Pulls submission results back
- Validates candidates against an existing identity database

Each provider has its own configuration — an endpoint URL, an authentication scheme, and any extra parameters.

## Configuring a provider

1. Open **Organization → Providers**.
2. Click **Add Provider**.
3. Pick the provider **type** (depends on what your deployment supports).
4. Enter the endpoint URL and credentials.
5. Save.

Sashakt encrypts provider credentials before storing them. They are never shown back to admins in plain text — only the last few characters of API keys are visible for verification.

## Security

- All provider credentials are encrypted at rest using a per-deployment encryption key
- Only System Admins can view or edit provider configuration
- Provider API calls happen server-side from Sashakt Core; credentials never reach the browser

:::caution Rotate credentials
Treat provider API keys like any other secret. Rotate them on a schedule, and immediately if anyone with admin access leaves your organization.
:::

## Testing a provider

After saving, click **Test Connection**. Sashakt makes a no-op request to the provider and reports success or failure.
