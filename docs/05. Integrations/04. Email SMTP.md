# Email (SMTP)

Sashakt sends a handful of transactional emails — welcome messages, password resets, certificate notifications. All of them go through your configured SMTP server.

> _📷 Screenshot placeholder: SMTP configuration form_

## When Sashakt sends email

| Event | Recipient |
|-------|-----------|
| New admin account created | The new user |
| Password reset requested | The user requesting |
| Test submitted (optional) | The candidate |
| Certificate issued (optional) | The candidate |

Optional emails can be toggled in [Organization Settings](../admin-portal/organization-settings).

## Setting it up

1. Pick an SMTP provider — common choices: SendGrid, Amazon SES, Mailgun, Google Workspace SMTP.
2. Create SMTP credentials there.
3. In Sashakt: **Organization Settings → Email**.
4. Enter:
   - **SMTP host** (e.g. `smtp.sendgrid.net`)
   - **Port** (typically `587` for STARTTLS, `465` for TLS)
   - **Username** and **password**
   - **From address** — the email address recipients see
5. Click **Send Test Email** to verify.

## DNS setup

To stay out of spam folders, configure these DNS records for your `From` domain:

- **SPF** — Authorize your SMTP provider
- **DKIM** — Add the keys your provider gives you
- **DMARC** — A policy record like `v=DMARC1; p=quarantine; rua=mailto:postmaster@yourdomain.org`

Your SMTP provider's documentation has the exact records. Skip this only at your peril — un-verified email looks suspicious.

:::tip Use a sub-domain for transactional mail
Sending from `mail.yourdomain.org` or `notifications.yourdomain.org` keeps your main domain's email reputation isolated from anything Sashakt sends.
:::
