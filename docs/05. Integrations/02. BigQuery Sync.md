# BigQuery Sync

Sashakt can stream your submissions and form responses to **Google BigQuery** for advanced analytics. Once connected, you can query, join, and visualize Sashakt data with the tools your team already uses (Looker, Data Studio, dbt, etc.).

> _📷 Screenshot placeholder: BigQuery sync configuration_

## What gets synced

- **Submissions** — One row per candidate attempt, with score and metadata
- **Form responses** — One row per submitted registration form
- **Tests** — Test metadata (id, name, tags, settings)
- **Questions** — Question bank (text, type, marks, tags)

Data syncs incrementally — only new or changed rows are pushed.

## Setting it up

1. In Google Cloud, create a BigQuery dataset for Sashakt.
2. Create a **service account** with `bigquery.dataEditor` and `bigquery.user` roles on that dataset.
3. Download the service account JSON key.
4. In Sashakt: **Organization Settings → Analytics → BigQuery**.
5. Upload the JSON key and enter the dataset name.
6. Save and click **Test Sync**.

A successful test pushes a sample row and confirms Sashakt can write to your dataset.

## Schema

Sashakt creates and maintains the necessary tables in your dataset. The schema is documented in the Portal under **Analytics → Schema reference** so your data team can plan joins.

:::tip Keep history clean
Don't manually edit Sashakt's BigQuery tables. The next sync will reconcile and overwrite changes. Build your derived tables (dbt models, views) on top of the raw tables instead.
:::

## Frequency

By default Sashakt syncs every 15 minutes. For real-time-ish dashboards this is usually plenty. Higher-frequency syncing can be configured by your Super Admin if needed.
