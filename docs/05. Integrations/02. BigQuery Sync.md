# BigQuery Sync

Sashakt streams your submissions and form responses to **Google BigQuery**. From there, your organization can connect **Looker Studio** (or any BI tool that talks to BigQuery) to build dashboards and reports that match what your team needs.

> _📷 Screenshot placeholder: BigQuery sync configuration_

## What gets synced

- **Submissions** — One row per candidate attempt, with score and metadata
- **Form responses** — One row per submitted registration form
- **Tests** — Test metadata (id, name, tags, settings)
- **Questions** — Question bank (text, type, marks, tags)

Data syncs incrementally — only new or changed rows are pushed.

## Setting it up

1. In Google Cloud, create a BigQuery dataset for Sashakt.
2. Create a **service account** with `bigquery.dataEditor` and `bigquery.user` roles on that dataset.
3. Download the service account JSON key.
4. In Sashakt: **Organization Settings → Analytics → BigQuery**.
5. Upload the JSON key and enter the dataset name.
6. Save and click **Test Sync**.

A successful test pushes a sample row and confirms Sashakt can write to your dataset.

## Connecting Looker Studio

Once data is flowing to BigQuery, point [Looker Studio](https://lookerstudio.google.com) at the dataset to build dashboards:

1. In Looker Studio, click **Create → Data source**.
2. Pick the **BigQuery** connector.
3. Select your project, dataset, and the tables Sashakt is populating.
4. Build charts and reports as usual.

Your org owns the dashboards end-to-end — you can shape them around the metrics your program actually tracks (completion rates, scores by region, cohort comparisons, and so on) without waiting on Sashakt to add new views.

## Schema

Sashakt creates and maintains the necessary tables in your dataset. The schema is documented in the Portal under **Analytics → Schema reference** so your data team can plan joins.

:::tip Keep history clean
Don't manually edit Sashakt's BigQuery tables. The next sync will reconcile and overwrite changes. Build your derived tables (or Looker Studio data sources) on top of the raw tables instead.
:::

## Frequency

By default Sashakt syncs every 15 minutes. For most reporting needs this is plenty. Higher-frequency syncing can be configured at the platform level if needed.
