# Google Cloud Storage

Sashakt uses **Google Cloud Storage (GCS)** to hold uploaded files — question images, certificate backgrounds, and form attachments. Audio and video for questions are linked by URL and stay on whichever service you host them on; only images live in GCS. Configuring GCS is part of any production deployment.

> _📷 Screenshot placeholder: Storage settings_

## What gets stored

| Type | Used for |
|------|---------|
| Images | Question media, certificate logos and backgrounds |
| PDFs | Imported certificates, test reference material |

User-uploaded files are uploaded directly to GCS — they don't pass through Sashakt Core, keeping the server light.

## Setting it up

1. In Google Cloud, create a **bucket** for Sashakt.
2. Create a **service account** with `storage.objectAdmin` on the bucket.
3. Download the service account JSON key.
4. In Sashakt: **Organization Settings → Storage**.
5. Upload the JSON key and enter the bucket name.

After saving, click **Test Upload**. A small test object is uploaded and immediately deleted to confirm permissions.

## Access control

Sashakt uses **signed URLs** for downloads — every download link is short-lived (a few minutes) and signed with your service account. This keeps your bucket private while still letting authorized candidates and admins access files.

You should keep the GCS bucket **private**. Sashakt's signed URLs are the only way files should be accessed.

## File size limits

- **Images** — Up to 5 MB per file (most organizations keep these much smaller)
- **PDFs** — Up to 20 MB

Larger limits can be raised at the platform level, but be mindful of bandwidth on the candidate side.
