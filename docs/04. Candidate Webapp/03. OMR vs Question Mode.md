# OMR vs Question Mode

Sashakt offers two ways to take a test. Depending on the test's settings, the candidate can either pick one or have it pre-chosen.

> _📷 Screenshot placeholder: Mode selection screen_

## Question mode (card style)

One question at a time fills the screen, with options below.

**Best for:** First-time test-takers. Anyone using a phone. Tests with question-by-question content like images, audio, video, or long stems.

**Why:** Each question gets full screen real estate, making it easy to focus.

> _📷 Screenshot placeholder: Question mode_

## OMR mode (bubble sheet)

A grid where each row is a question and the columns are options. Candidates tap a bubble to answer.

**Best for:** Candidates familiar with traditional paper-based bubble sheets. Quick recall tests with short, similar options (single letters, numbers).

**Why:** Many questions visible at once means very fast navigation for experienced test-takers.

> _📷 Screenshot placeholder: OMR mode_

## Which one to pick

| Question mode | OMR mode |
|--------------|----------|
| Slower, more focused | Faster, more parallel |
| Better for long stems | Better for short stems |
| Great on mobile | Better on larger screens |
| Always shows one item | Shows many at once |

If the admin made both modes available, the candidate sees a one-time chooser before starting. The choice can't be changed mid-test, so admins should make sure the candidate understands both.

## Choosing on behalf of candidates

When designing a test, admins can lock the mode. Surveys and structured forms often work better in OMR mode; long-form reading tests usually want question mode. See [Test Settings](../admin-portal/tests/test-settings).
