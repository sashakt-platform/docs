# Timer, Mark for Review & Progress

This page covers the three tools candidates use to manage their attempt — the timer, Mark for Review, and the progress indicator.

![Test screen with timer and palette](/img/screenshots/webapp-test-taking.png)

## The timer

The timer sits at the top of every test screen. It counts down the time remaining.

### What happens when the timer hits zero

Sashakt **auto-submits** whatever the candidate has answered so far. Skipped and unanswered questions are submitted blank.

There is no extension — admins set the duration in [Test Settings](../admin-portal/tests/test-settings#test-schedule) before the test starts and it cannot be changed mid-attempt.

### Pausing the timer

If your organisation has [Pause Test](../admin-portal/organization-settings#pause-test) enabled, candidates can pause and resume during their attempt. Otherwise the timer keeps running on the server side. If a candidate closes the browser, re-opening the test link picks up where they left off — with the time that has actually elapsed.

## Mark for Review

Each question card has a **Mark for review** button. Marked questions:

- Show flagged in the Question Palette on the right
- Make it easy to find anything you're unsure about
- Don't change scoring — they're a UI hint only

Common strategy: answer everything you know on first pass, mark anything you're unsure about, use remaining time to revisit marked questions.

Mark for Review is controlled at the organisation level — your organisation may have it turned off, in which case candidates won't see the button.

## Progress indicator

At the bottom of the test screen, candidates see a running count:

`Page 1 of 3 | 1–1 of 3 Questions`

The Question Palette on the right side gives a fuller picture — each square shows whether that question is unanswered, answered, mandatory, or marked for review.

## Instructions

The **Instructions** button in the top bar reopens the test's pre-test guidelines at any time.
