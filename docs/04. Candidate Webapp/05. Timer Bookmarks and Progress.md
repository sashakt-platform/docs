# Timer, Bookmarks & Progress

This page covers the three tools candidates use to manage their attempt — the timer, bookmarks, and the progress indicator.

> _📷 Screenshot placeholder: Timer in the top bar_

## The timer

The timer sits at the top of every test screen. It counts down the time remaining and turns red in the final two minutes as a warning.

### What happens when the timer hits zero

Sashakt **auto-submits** whatever the candidate has answered so far. Skipped and unanswered questions are submitted blank.

There is no extension — admins set the duration in [Test Settings](../admin-portal/tests/test-settings) before the test starts and it cannot be changed mid-attempt.

### Pausing the timer

The timer cannot be paused by the candidate. If a candidate closes the browser, the timer keeps running on the server side. Re-opening the test link picks up where they left off — with the time that has actually elapsed.

## Bookmarking

The **Bookmark** icon on every question marks it for later review. Bookmarked questions:

- Show in orange in the question palette
- Can be filtered with the **Show bookmarked only** toggle
- Are reset if the candidate restarts the test

Common strategy: answer everything you know on first pass, bookmark anything you're unsure about, use remaining time to revisit bookmarks.

## Progress indicator

At the top of the test screen, candidates see:

- **Number answered** / **total questions**
- A progress bar that fills as they answer

The progress indicator is purely visual feedback — answering more questions doesn't change the time available or the test's behavior.

## Before submitting

When the candidate clicks **Submit**, Sashakt shows a summary:

- Total questions
- Answered
- Skipped or unanswered
- Bookmarked

Candidates can go back and finish bookmarked items before confirming.
