# Taking a Test

This page walks through what a candidate sees from the moment they open a test link to the moment they submit. Admins should read this once to understand the candidate experience.

## 1. Landing page

When a candidate opens a test link (a URL like `https://assessment.sashakt.in/test/<test-id>`), they see:

- The **test name** and short description
- A **Test Overview** card with total questions, test duration, and questions per page
- The **Start Test** button

![Test landing page](/img/screenshots/webapp-landing.png)

## 2. Registration

After clicking **Start Test**, the candidate fills in the [registration form](./registration-form) the admin attached to the test.

![Registration form](/img/screenshots/webapp-registration.png)

If the form is short, this only takes a minute.

## 3. The test itself

The candidate answers each question and navigates with **Previous** / **Next**. A persistent **timer** sits in the top bar, alongside an **Instructions** button that reopens the test's pre-test guidelines.

![Test taking screen](/img/screenshots/webapp-test-taking.png)

A [Question Palette](./question-palette-and-navigation) on the right shows progress at a glance. Each question card includes a marks indicator and a **Mark for review** button.

## 4. Submitting

When the candidate is done — or the timer runs out — they submit. Sashakt grades the test (for objective questions) and shows the result page with the [Test Completion Message](../admin-portal/tests/test-settings#test-completion-message) the admin wrote.

## 5. Result

Depending on test settings, the candidate sees:

- Final score (if **Show result after test completion** is on)
- A **Download Certificate** button (if they qualify)

See [Submitting & Results](./submitting-and-results) for the full breakdown.
