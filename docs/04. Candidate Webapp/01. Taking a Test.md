# Taking a Test

This page walks through what a candidate sees from the moment they open a test link to the moment they submit. Admins should read this once to understand the candidate experience.

> _📷 Screenshot placeholder: Test landing page_

## 1. Landing page

When a candidate opens a test link, they see:

- The **test name** and a short description
- **Instructions** — duration, scoring, what to expect
- The **Start Test** button

If the test has a timer, the landing page clearly says how much time the candidate will have.

## 2. Registration

After clicking **Start Test**, the candidate fills in the [registration form](./registration-form). If the form is short, this only takes a minute.

If the test allows it, returning candidates can resume an in-progress attempt from this screen rather than starting over.

## 3. Mode selection (if enabled)

If the test offers a choice between **OMR mode** and **Question mode**, the candidate picks one here. See [OMR vs Question Mode](./omr-vs-question-mode) for the difference.

## 4. The test itself

The candidate answers each question and navigates with **Next** / **Previous**. A [question palette](./question-palette-and-navigation) on the side shows progress at a glance.

A persistent **timer** shows how much time is left.

> _📷 Screenshot placeholder: Question-taking screen with palette_

## 5. Submitting

When the candidate is done — or the timer runs out — they submit. Sashakt grades the test (for objective questions) and shows the result page.

## 6. Result

Depending on test settings, the candidate sees:

- Final score
- Pass/fail status
- A review of every question (if feedback is enabled)
- A **Download Certificate** button (if they qualify)

See [Submitting & Results](./submitting-and-results) for the full breakdown.
