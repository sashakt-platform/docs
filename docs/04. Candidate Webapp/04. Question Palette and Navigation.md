# Question Palette & Navigation

The **question palette** is the panel on the side of a test that shows every question at a glance. It's how candidates skip around without losing their place.

> _📷 Screenshot placeholder: Test with question palette open on the side_

## Reading the palette

Each square in the palette represents one question. Its color tells you the status:

- **Gray** — Not visited
- **Blue** — Currently active
- **Green** — Answered
- **Orange** — Bookmarked for review
- **Red** — Visited but skipped

Candidates can tap any square to jump straight to that question.

## Navigation buttons

At the bottom of every question card:

- **Previous** — Go back one question
- **Skip** — Move to the next question without answering
- **Next** — Save the current answer and move forward

There's no penalty for using **Skip** — candidates can come back to skipped questions via the palette.

## Bookmarking

The **Bookmark** button on each question marks it for later review. Bookmarked questions show up in orange in the palette, making them easy to find before submitting.

A common strategy: answer the easy questions first, bookmark the hard ones, then come back to them with the time left.

## Section navigation

If the test has multiple [sections](../admin-portal/tests/sections-and-question-selection), the palette is grouped by section. Some tests lock each section — once you move on, you can't go back. The interface makes this clear before the candidate confirms moving on.

## Submitting from anywhere

The **Submit** button is always available in the navigation bar. Candidates don't have to be on the last question to submit. Sashakt asks for confirmation before finalizing.
