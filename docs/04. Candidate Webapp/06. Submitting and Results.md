# Submitting & Results

The final stretch of a test attempt — what candidates see when they submit and the result they get.

> _📷 Screenshot placeholder: Results page_

## Submitting

Candidates can submit at any time using the **Submit** button. Before finalizing, Sashakt shows a confirmation screen with:

- How many questions they answered
- How many they skipped or left blank
- Whether they have bookmarked questions still pending

A candidate can cancel and go back, or confirm and submit.

Once submitted, an attempt cannot be reopened. Any unanswered questions are graded as blank.

## How results are shown

What appears on the result page depends on the test's feedback setting:

### No feedback

The candidate sees only "Your test has been submitted. Thank you." — useful for high-stakes exams where the admin will release results separately.

### Score only

The candidate sees their final score and pass/fail status, but no breakdown by question.

### Full review

The candidate sees every question with:

- Their answer
- The correct answer
- Marks awarded
- An optional explanation, if the admin added one

This mode is excellent for learning-focused tests.

## Certificates

If the candidate qualifies (based on the test's passing criteria), a **Download Certificate** button appears on the result page. See [Certificate Download](./certificate-download).

## Re-attempting

A candidate can only attempt a test once.
