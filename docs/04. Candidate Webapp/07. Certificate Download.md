# Certificate Download

When a candidate passes a test that issues certificates, they can download a personalized certificate right from the result page.

> _📷 Screenshot placeholder: Result page with Download Certificate button_

## What the certificate looks like

The certificate is generated from the template an admin designed in the Portal (see [Designing a Certificate](../admin-portal/certificates/designing-a-certificate)). Each certificate is personalized with the candidate's name, score, the test name, the date, and a unique verification URL.

## Downloading

1. On the result page, click **Download Certificate**.
2. Sashakt generates a PDF and starts the download.

The PDF is shareable — candidates can attach it to job applications, email it, or print it.

## Verification

Every certificate includes a **verification URL** at the bottom. Anyone — an employer, a school, a partner organization — can open that URL to confirm:

- The certificate is genuine
- It was issued to the named candidate
- For the named test
- On the stated date
- With the stated score

This makes Sashakt certificates trustworthy in a way that a paper-only certificate isn't.

> _📷 Screenshot placeholder: Verification page_

## Re-downloading

Candidates can return to the result page later — using the same browser or by following a return link — to download the certificate again. There's no expiry.

If a candidate has lost access to their browser session, an admin can re-issue the certificate from the Portal.
