# Certificate Download

When a candidate passes a test that issues certificates, they can download a personalized certificate right from the result page.

> _📷 Screenshot placeholder: Result page with Download Certificate button_

## What the certificate looks like

The certificate is generated from a Google Slides template the admin set up (see [Designing a Certificate](../admin-portal/certificates/designing-a-certificate)). Each certificate is personalized with the candidate's name, score, the test name, the date, and any other tokens the template uses.

## Downloading

1. On the result page, click **Download Certificate**.
2. Sashakt generates a PDF and starts the download.

The PDF is shareable — candidates can attach it to job applications, email it, or print it.

## Re-downloading

Candidates can return to the result page later — using the same browser or by following a return link — to download the certificate again. There's no expiry.

:::tip Don't lose your link
There's no admin-side way to re-send a certificate, so candidates should keep their result page link (and the downloaded PDF) somewhere safe.
:::
