# Language Switching (EN/HI)

The Sashakt Webapp is bilingual — candidates can switch between **English** and **Hindi** at any point during their attempt without losing progress.

> _📷 Screenshot placeholder: Language switcher in the top corner_

## How candidates switch languages

The language switcher sits in the top corner of every screen — typically a globe icon or an `EN | हिन्दी` toggle. Clicking it switches the interface immediately.

The change applies to:

- All navigation labels and buttons
- The registration form's labels and placeholders
- Instructions and error messages

## What about question content?

Interface text translates automatically. **Question content** — the question text and options — only translates if the admin provides translations when authoring the question.

If a question is authored only in English, candidates see it in English even if they've switched the interface to Hindi. The opposite is also true.

:::tip Authoring bilingual questions
To serve both languages cleanly, author each question with both English and Hindi text. Sashakt picks the right version based on the candidate's chosen language.
:::

## Mid-test switching

Switching languages mid-test is safe — answers given so far are preserved. This is useful when a candidate is more comfortable reading the question stem in one language but the options in another.

## What's not translated

- **Candidate names** entered during registration
- **Free-text answers** typed by the candidate
- **Certificates** — these use whatever language the admin authored the template in
