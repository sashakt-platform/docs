# Creating a Test

A **test** is the thing your candidates actually take. Sashakt walks you through three steps to build one.

![Tests list](/img/screenshots/tests-list.png)

## Two ways to start

From the Tests page you can either:

- **Create Manually** — Start from a blank test
- **Create from Test Template** — Start from a [test template](./test-templates) with settings pre-filled

Both options drop you into the same three-step wizard.

## Step 1 — Primary Details

![Primary Details step](/img/screenshots/test-edit-primary.png)

Give the test:

- A clear **Test Name** — candidates will see this
- An optional **Description** — candidates will see this too
- **Tag Types** and **Tags** — categorize the test (e.g. _Subject: Math_)
- Optionally a **State** and **District** to scope the test to a region
- **Test Status** — Active by default

## Step 2 — Select Questions

![Select Questions step](/img/screenshots/test-edit-questions.png)

Pick the questions for this test using one of two modes:

- **Manual Selection** — Browse the question bank and add questions one by one
- **Auto Selection** — Pull questions automatically by tags

See [Sections & Question Selection](./sections-and-question-selection) for the details on each mode.

## Step 3 — Test Configuration

![Test Configuration step](/img/screenshots/test-edit-configuration.png)

Set how the test behaves: schedule, candidate experience (pre-test guidelines, completion message, language, form, certificate), and test rules (shuffle, random selection, show marks, show result).

See [Test Settings](./test-settings) for every configuration option.

## Save and share

Click **Save** at the top of Step 3. Sashakt generates a unique link for the test. From the Tests list, use:

- **Edit** — Go back into the wizard
- **Download QR** — Get a printable QR code for the candidate link
- **Open menu → Copy Test Link** — Copy the URL to share with candidates
- **Open menu → View Report** — Quick status counts (Total, Submitted, Not submitted, Active, Inactive)
- **Open menu → Duplicate** — Clone the test as a starting point
- **Open menu → Delete** — Remove the test
