# Question Selection

In **Step 2** of the test wizard, Sashakt offers two ways to add questions: **Manual Selection** and **Auto Selection**.

## Manual Selection

You pick each question yourself by browsing the [question bank](../question-bank/creating-questions).

![Manual selection](/img/screenshots/test-edit-questions.png)

1. Click **+ Add more questions** to open the question picker.
2. Search, filter by state, tag types, or tags.
3. Tick the questions you want.
4. Confirm to add them to the test.

Good when you want exact control over which questions a candidate sees — e.g. a curated mock test or a fixed-form assessment.

## Auto Selection

Sashakt picks questions automatically by tag.

![Auto selection](/img/screenshots/test-edit-auto-selection.png)

1. Switch to the **Auto Selection** tab.
2. Choose the **tags** the test should pull from.
3. Set how many questions to include.

Good when you want every test attempt drawn from a pool — useful for randomized assessments. Combine with **Select random questions per candidate** (in [Test Settings → Test Rules](./test-settings)) to give every candidate a different subset.

## Manual vs Auto — when to use which

| Use Manual when… | Use Auto when… |
|------------------|----------------|
| The question set is curated | The pool is the source of truth |
| You want predictable test content | You want variety per candidate |
| It's a mock or sample test | It's a high-stakes test where cheating risk matters |
