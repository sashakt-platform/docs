# Sections & Question Selection

Sections let you group questions into logical chunks — _Reading_, _Math_, _General Knowledge_ — each with its own rules.

> _📷 Screenshot placeholder: Test with three sections_

## Why use sections?

- **Different timers** per section — e.g. 20 minutes for Reading, 30 for Math
- **Different shuffling** rules per section
- **Reorder** sections so candidates see them in a specific order
- **Section-level scoring** in reports

If your test is short and simple, you don't need sections at all. A single-section test works fine.

## Creating a section

Inside the test editor, click **Add Section**. Give it a name, then add questions to it.

You can:

- Reorder sections by drag-and-drop
- Move a question from one section to another
- Set a section to be **mandatory** or **optional**

## Random selection from a pool

For high-stakes tests, you usually want each candidate to see a different set of questions. Inside a section you can configure:

- **Pool** — A larger set of questions (e.g. 50 tagged _Class 8 Algebra_)
- **Pick** — How many to serve each candidate (e.g. 10)

Sashakt picks _N_ questions from the pool randomly per candidate. Combined with **shuffle options**, this is the standard pattern for fair, hard-to-cheat tests.

## Shuffling

Two shuffle controls:

- **Shuffle questions within section** — Each candidate sees the section's questions in a different order.
- **Shuffle options within question** — Each candidate sees option A, B, C, D in a different order.

Both are independent toggles — turn on what makes sense for your context.
