# Test Templates

A **test template** is a saved set of test settings — duration, scoring rules, OMR mode, feedback options, candidate experience, and so on — that you can apply to new tests in one click.

If you find yourself running the same kind of test over and over (weekly quizzes, certification exams, baseline assessments), templates save time and keep things consistent.

![Test Templates page](/img/screenshots/test-templates.png)

Test Templates are a top-level section in the left navigation, separate from Tests.

## Creating a template

Open **Test Templates** and click **Create**. The template editor looks just like the test editor, but instead of a test you save a reusable configuration.

Templates capture **settings**, not questions. When you create a test from a template, you'll choose questions fresh — but timing, scoring, candidate experience, and rules come pre-filled.

## Using a template

When you click **Create Test** from the Tests page, choose **Create from Test Template**. Sashakt asks which template to use, then drops you into the test wizard with all settings pre-filled.

## Editing a template

Open **Test Templates** to see all saved templates. Edit a template to change its defaults — existing tests built from it are not affected.

## When to use templates vs duplicating

- **Template** — Reusing settings across many *new* tests with different questions.
- **Duplicate** — Cloning an existing test (questions and all) as a starting point. Use the **Duplicate** menu option in the Tests list.

Both have their place. Templates are about reusable rules; duplicates are about reusable content.
