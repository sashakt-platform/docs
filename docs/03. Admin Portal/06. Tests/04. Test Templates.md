# Test Templates

A **test template** is a saved set of test settings — duration, scoring rules, OMR mode, feedback options, and so on — that you can apply to new tests in one click.

If you find yourself running the same kind of test over and over (weekly quizzes, certification exams, baseline assessments), templates save time and keep things consistent.

> _📷 Screenshot placeholder: Test templates list_

## Saving a template

While editing a test, click **Save as Template**. Give it a clear name like _Weekly Math Quiz Template_ or _Class 10 Certification_.

Templates capture **settings**, not questions. The next time you create a test from this template, you'll choose questions fresh — but timing, scoring, and feedback come pre-filled.

## Using a template

When you click **Create Test**, you can choose to start from:

- A blank test, or
- An existing template

Pick the template, and Sashakt pre-fills the new test with all the saved settings.

## Editing a template

Open **Tests → Templates** to see all saved templates. Edit a template to change its defaults — existing tests built from it are not affected.

## When to use templates vs duplicating

- **Template** — Reusing settings across many *new* tests with different questions.
- **Duplicate** — Cloning an existing test (questions and all) as a starting point.

Both have their place. Templates are about reusable rules; duplicates are about reusable content.
