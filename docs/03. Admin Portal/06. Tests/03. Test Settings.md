# Test Settings

When you create or edit a test, Sashakt walks you through a three-step wizard. **Step 3 — Test Configuration** is where most of the per-test rules live.

![Test Configuration step](/img/screenshots/test-edit-configuration-expanded.png)

The page groups everything into three collapsible sections.

## Test Schedule

Sets when the test is available to candidates.

- **Start Time** — When the test opens
- **End Time** — When the test closes

Outside this window the test link doesn't accept new attempts. In-progress attempts at the cutoff are auto-submitted (subject to the timer settings).

## Candidate Experience

This section shapes what the candidate sees from the moment they open the link to the moment they finish.

### Pre-test Guidelines

Rich-text instructions shown on the test's landing page and inside the test (via the **Instructions** button in the top bar). Use it for anything the candidate needs to know: stable internet, no calculators, how scoring works.

The editor supports headings, bold/italic/underline, lists, links, highlight colour, and math formulas.

### Test Completion Message

Rich-text message shown after the candidate submits. Common uses: "Thank you for completing the assessment", "Your certificate has been emailed", or program-specific next steps.

### Language

Set the language the test will be displayed in — **English** or **Hindi**. The candidate sees the test entirely in this language; they cannot switch mid-test.

### Candidate Information Form

The [form](../forms/form-builder) candidates fill in before they start the test. Pick from your existing forms or default to "Candidate Profile".

### Certificate

The [certificate](../certificates/designing-a-certificate) issued to qualifying candidates. Leave it blank if this test doesn't issue certificates.

## Test Rules

Behaviour during the test itself.

- **Shuffle question order per candidate** — Each candidate sees questions in a different order
- **Select random questions per candidate** — Serves a random subset of the test's question pool to each candidate. Set the number of questions to serve.
- **Show marks to candidate during test** — Whether each question shows its marks while the candidate answers it
- **Show result after test completion** — Whether the candidate sees their score on the result page

## Settings inherited from the organisation

A test also picks up the [Organisation Settings](../organization-settings) defaults — timer, marking scheme, OMR mode, Question Palette, Mark for Review, Pause Test, and so on. If those settings are marked **Flexible**, you can override them per test. If they're **Fixed**, you don't see the option.
