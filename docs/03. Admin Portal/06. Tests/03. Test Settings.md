# Test Settings

Test settings control how candidates experience the test — how long they have, how it's scored, what they see at the end.

> _📷 Screenshot placeholder: Test settings panel_

## Timing

- **Test duration** — Total time, in minutes
- **Section duration** — Per-section timer (if sections are enabled)
- **Auto-submit** — When the timer expires, Sashakt submits whatever the candidate has answered so far

There is no "extend on the fly" — if you want candidates to have more time, edit the test before they start.

## Scoring

- **Marks per question** — Default marks awarded for a correct answer
- **Negative marks** — Marks deducted for an incorrect answer (set to 0 for no negative marking)
- **Partial marking** — For multi-choice and matrix items
- **Passing score** — Optional threshold that determines pass/fail status on the result page and on certificates

## OMR mode

If OMR is enabled for your organization, you can let candidates choose between:

- **Question mode** — One question at a time in card style (default)
- **OMR mode** — A bubble-sheet style answer grid

When OMR mode is enabled at the test level, candidates see a choice screen before starting. See [OMR vs Question Mode](../../candidate-webapp/omr-vs-question-mode).

## Feedback

Decide what the candidate sees after they submit:

- **No feedback** — Only the final score
- **Score only** — Final score and pass/fail
- **Review answers** — Every question with their answer and the correct answer

Reviewing answers is great for learning contexts but inappropriate for live exams that may be reused.

## Certificates

If certificates are enabled, attach a [certificate template](../certificates/designing-a-certificate). Sashakt issues a certificate to any candidate who meets the passing criteria.

## Accessibility

- **Show timer** — Some tests choose to hide the visible timer to reduce anxiety
- **Allow bookmarking** — Candidates can flag questions to return to
- **Question palette** — Show or hide the side panel listing all questions
