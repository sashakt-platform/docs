# Question Types

When you create a question, Sashakt asks you to pick a type. Types are grouped into **Commonly Used** and **Advanced**.

![Choose Question Type dialog](/img/screenshots/question-types-chooser.png)

## Commonly Used

### Single/Multiple Choice

One question type covers both _pick one_ and _pick many_ — Sashakt automatically detects which mode applies based on how many options you mark as correct.

- Mark **one** option correct → renders as a single-choice (radio button) question
- Mark **two or more** options correct → renders as a multi-choice (checkbox) question

You can add as many options as you need with **Add Row**. Each option can carry its own attachment (image, audio, video).

Good for: classic multiple-choice quizzes, "select all that apply" items, recall questions.

### Subjective

A free-text response field. Use it for short answers, reasoning, or opinions.

Subjective answers are **not auto-scored** — they flow to BigQuery along with the rest of the submission, where your team reviews them in Looker Studio.

### Numerical

The candidate enters a number. Good for math, calculations, measurements, and anything with one objectively right numeric answer.

## Advanced — Matrix

Matrix questions are grids where each row is a sub-item. Sashakt supports four variants:

- **Matrix Text** — Each row takes a short text answer
- **Matrix Number** — Each row takes a numeric answer
- **Matrix Match** — Match items in one column to items in another
- **Matrix Rating** — Each row rated on the same scale (e.g. 1–5)

Good for: surveys, multi-part questions, structured comparisons, rating scales.

## Marking scheme

Every question has its own marking scheme — set in the question editor:

- **Correct** — Marks awarded for a fully correct answer
- **Incorrect** — Marks deducted for a wrong answer (set to 0 for no negative marking)
- **No answer** — Marks for a blank/skipped question (typically 0)

Your organization's default marking scheme is set in [Organization Settings](../organization-settings) and can be locked (Fixed) or made overridable per question (Flexible).

## Set Question as Mandatory

A mandatory question must be answered before a candidate can submit the test. Set this per question in the editor.
