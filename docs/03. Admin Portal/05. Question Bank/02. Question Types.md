# Question Types

Sashakt supports several question types. Pick the one that matches what you're actually measuring — the right type makes scoring fair and analysis meaningful.

## Single-choice

Candidates pick **exactly one** option from a list.

Good for: classic multiple-choice quizzes, recall questions, opinion items.

> _📷 Screenshot placeholder: Single-choice in the candidate view_

## Multi-choice

Candidates pick **one or more** options. You decide whether they need all correct options to get full marks, or whether **partial marking** awards credit for each correct selection.

Good for: "select all that apply" items, evaluating breadth of knowledge.

## Subjective

A free-text response field. You can set a **character limit** to keep answers focused.

Good for: short answers, reasoning, opinion. Subjective answers are not auto-scored — they flow to BigQuery alongside the rest of the submission data, where your team can review them in Looker Studio.

## Numerical

The candidate enters a number. You set the expected answer and an optional **tolerance** range.

- **Integer** — Whole numbers only
- **Decimal** — Allows decimals with a configurable number of places

Good for: math, calculations, measurements.

## Matrix

A grid where each row is a sub-question. Sashakt supports three matrix variants:

- **Matrix rating** — Each row rated on the same scale (e.g. 1–5)
- **Matrix matching** — Match items in column A to items in column B
- **Matrix input** — Each cell takes a text or numerical input

Good for: surveys, multi-part questions, structured comparisons.

> _📷 Screenshot placeholder: Matrix rating in the candidate view_

## Partial marking

For multi-choice and matrix questions, partial marking awards credit per correct row/option rather than all-or-nothing. Set it per question.
