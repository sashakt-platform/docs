# Media in Questions

You can attach **images** and **audio** to any question. This is essential for diagrams, listening comprehension, photo identification, and a lot more.

> _📷 Screenshot placeholder: Question editor with an image attached_

## Adding an image

1. Open a question for editing.
2. Click **Add Image** in the question editor.
3. Either drag a file in or click to choose one.
4. Save.

The image appears above the question text in the candidate view.

**Supported formats:** PNG, JPG, GIF, WebP.

**Size limits:** Keep images under 1 MB where possible. Large files slow down low-bandwidth candidates.

:::tip Use clear, compressed images
Aim for ~150 KB per image. Diagrams render best as PNG, photographs as JPG. Test on a phone before publishing.
:::

## Adding audio

Useful for listening tests, language assessments, and accessibility.

1. Open a question for editing.
2. Click **Add Audio**.
3. Upload an MP3 or WAV file.

The candidate sees a play button above the question. They can play the clip multiple times (unless your organization has restricted this).

**Supported formats:** MP3, WAV.

**Size limits:** Keep clips under 2 MB. Long clips eat bandwidth and battery.

## Where media is stored

Uploaded media is stored in your organization's connected storage (typically Google Cloud Storage) — not bundled with the question itself. This keeps the question bank fast and allows the same image to be reused across many questions.
