# Creating Questions

The **Question Bank** is your reusable library of questions. Build it up once and you can pull from it across as many tests as you like.

![Question Bank listing](/img/screenshots/question-bank.png)

## Add a single question

1. Open **Question Bank** from the left navigation.
2. Click **Create Question**.
3. Choose a **question type** — see [Question Types](./question-types) for what each one is for.
4. Enter the question text and any **additional instructions** (e.g. time hints, reference material).
5. Add options (for choice-based types) and mark the correct answer(s).
6. Set **marking scheme** — Correct / Incorrect / No answer marks.
7. Attach **tag types** and **tags** so you can find the question later.
8. Optionally scope the question to a **state**.
9. Toggle **Set Question as Mandatory** if candidates must answer it before submitting.
10. Click **Save**.

![Create Question editor](/img/screenshots/question-create.png)

The question is now in your bank and available to every test you create.

## Editing and revisions

Open any question to edit it. Every save creates a **new revision** of the question.

When a question is added to a test, the test is linked to that specific revision — not to the question generally. So even if you edit a question later, **tests that already use the earlier revision continue to use the earlier revision**. Candidates taking a live test never see a version they weren't supposed to.

If you want a test to pick up your edits, add the latest revision to the test explicitly.

:::tip Why revisions matter
Revisions are how Sashakt keeps test integrity intact. You can confidently edit, correct, or improve questions in the bank without worrying about disturbing tests that are already running or already graded.
:::

## Question Status

Each question has an **Active** / **Inactive** toggle. Inactive questions stay in your bank but can't be added to new tests until reactivated.
