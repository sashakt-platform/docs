# Bulk Upload (CSV)

When you have dozens — or hundreds — of questions to add, the CSV bulk upload is the fastest path. Fill in a spreadsheet, upload, and Sashakt does the rest.

> _📷 Screenshot placeholder: Bulk upload screen with download template button_

## Step 1 — Download the template

Open **Question Bank → Bulk Upload** and click **Download Template**. You'll get a CSV with the right columns already in place.

The template includes columns for:

- Question text
- Question type
- Options (multiple columns)
- Correct answer
- Tags (optional)
- State Location (optional)

## Step 2 — Fill it in

Open the template in any spreadsheet tool (Google Sheets, Excel, LibreOffice). Each row is one question.

:::tip Tags
Separate multiple tags with the `|` character — e.g. `Mathematics|Class 8|Algebra`.
:::

## Step 3 — Upload

Save the file as CSV and upload it back. Sashakt will:

1. Validate every row
2. Show you a preview with any errors highlighted
3. Wait for your confirmation before importing

> _📷 Screenshot placeholder: Validation preview with row-level errors_

## Common validation errors

- **Unknown question type** — Check the spelling against the template's accepted values.
- **Missing correct answer** — Every choice question needs one or more correct options marked.
- **Unknown tag** — Either create the tag first in the [Tags](../tags) section or remove it from the row.
- **Invalid characters** — Some spreadsheet tools auto-convert quotes or dashes. Stick with plain text.

Fix the errors in your spreadsheet and re-upload. Valid rows from a partial upload are saved; only the flagged rows need a second pass.
