# Entities

**Entities** are the real-world things your organization manages — usually **locations** (states, districts, blocks, villages) or **institutions** (schools, training centers, colleges).

Entities power two important parts of Sashakt:

1. **Scoped roles** — A State Admin is scoped to a state; a Test Admin can be optionally scoped to a state or district.
2. **Forms** — Registration forms can use entity hierarchies as dropdowns (pick a state → districts filter automatically).

## Entity types

Common entity types include:

- **State**
- **District**
- **Block / Taluka**
- **Village / Town**
- **School / Institution**

Your System Admin defines which entity types are active for your org.

## Hierarchy

Entities form a parent-child tree. A typical structure looks like:

```
India
├── Maharashtra
│   ├── Pune District
│   │   ├── Pune City
│   │   └── Pimpri-Chinchwad
│   └── Mumbai District
└── Karnataka
    └── Bengaluru District
```

When a candidate fills a form, picking _Maharashtra_ filters the district dropdown to only Maharashtra's districts. The hierarchy makes forms fast and prevents bad data.

## Adding entities

1. Open **Entities** from the left navigation.
2. Choose the **type** you're adding (e.g. _District_).
3. Pick the **parent** entity (e.g. _Maharashtra_).
4. Enter the name and any codes (census code, state code, etc.).
5. Save.

## Bulk operations

For large hierarchies — say, all districts in a country — Sashakt supports bulk operations on entities. Check with your System Admin for the upload template if you're seeding entities from scratch.
