# Entities

An **entity** is a custom organizational unit defined by your organization. Unlike locations, which represent geographical hierarchies, entities represent the operational units you work with, such as Schools, Training Centres, Wards, or Self-Help Groups (SHGs).

![Entities list](/img/screenshots/entities.png)

Entities power two important parts of Sashakt:

1. **Scoped roles** — A State Admin is scoped to a state; a Test Admin can optionally be scoped to a state or district.
2. **Forms** — Registration forms include **State / District / Block / Entity** fields that pull options directly from your entity hierarchy.



Your System Admin defines which entities are applicable for your org.

| Entity           | Example                          |
| ---------------- | -------------------------------- |
| School           | Government High School, Pune     |
| Ward             | Ward No. 12                      |
| Training Centre  | Skill Development Centre, Nashik |
| SHG              | Jai Bhavani SHG                  |
| Hospital         | District Hospital, Kolhapur      |
| Anganwadi Centre | Anganwadi Centre 45              |


## Scoping an Entity to a location

Entities can optionally be scoped to a location, allowing them to exist only within a specific geographical area.

For example, if your organization has an entity called SHG (Self-Help Group), you can create its record named Jai Bhavani SHG and associate it with the Ambala district in Haryana. This ensures that this particular record is available only within its assigned location.

When a candidate takes a Sashakt assessment or fills out a form, you can require them to select an entity. Sashakt automatically filters the available entities based on the candidate's selected or assigned location, making it easier to choose the correct one.

## Adding an Entity

An entity defines the type of object your organization wants to manage, such as **SHG**, **School**, **Training Centre**, or **Ward**.

1. Open **Entities** from the left navigation.
2. Click **Create Entity**.
3. Enter the **Entity Name** (for example, **SHG**) and an optional description.
4. Click **Save**.


## Adding Records to an Entity

Records are individual instances of an entity. For example, if **SHG** is an entity, **Jai Bhavani SHG** is one of its records.

1. Open the required entity and click **View Records**.
2. Click **Add SHG Record** (or **Add Record**, depending on the entity type).
3. Enter the **Name** (for example, **Jai Bhavani SHG**) and an optional description.
4. Optionally, associate the record with a **State**, **District**, or **Block** to scope it to a specific location.
5. Click **Save**.
