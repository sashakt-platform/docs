# Entities

**Entities** are the real-world things your organisation manages — usually **locations** (states, districts, blocks) or **institutions** (schools, training centres, colleges).

![Entities list](/img/screenshots/entities.png)

Entities power two important parts of Sashakt:

1. **Scoped roles** — A State Admin is scoped to a state; a Test Admin can optionally be scoped to a state or district.
2. **Forms** — Registration forms include **State / District / Block / Entity** fields that pull options directly from your entity hierarchy.

## Entity types

Common entity types include:

- **State**
- **District**
- **Block / Taluka**
- **School / Institution**

Your System Admin defines which entity types are active for your org.

## Hierarchy

Entities form a parent-child tree. A typical structure looks like:

```
India
├── Maharashtra
│   ├── Pune District
│   │   ├── Pune City Block
│   │   └── Sample High School (Ahmednagar)
│   └── Mumbai District
└── Karnataka
    └── Bengaluru District
```

When a candidate fills a form, picking _Maharashtra_ filters the district dropdown to only Maharashtra's districts. The hierarchy makes forms fast and prevents bad data.

## Adding entities

1. Open **Entities** from the left navigation.
2. Click **Create Entity**.
3. Choose the **type** you're adding (e.g. _District_).
4. Pick the **parent** entity (e.g. _Maharashtra_).
5. Enter the name and any codes (census code, state code, etc.).
6. Save.
