# Tokens & Variables

Tokens are placeholders you drop into your Google Slides certificate template that Sashakt replaces with each candidate's actual values when the certificate is generated.

> _📷 Screenshot placeholder: A Google Slide with token placeholders_

## Available tokens

| Token | Replaced with |
|-------|---------------|
| `{{candidate_name}}` | Candidate's full name |
| `{{test_name}}` | The test's name |
| `{{score}}` | Numeric score (e.g. `45`) |
| `{{score_percentage}}` | Score as a percentage (e.g. `90%`) |
| `{{date}}` | Date the test was completed |
| `{{organization_name}}` | Your organization's name |
| `{{state}}` | Candidate's registered state |
| `{{district}}` | Candidate's registered district |

Custom tokens that map to your form fields may also be available (e.g. `{{batch_code}}`, `{{employee_id}}`). Check with your System Admin about which custom tokens your deployment supports.

## Using a token in Google Slides

Just type the token into a text box where you want the value to appear:

```
Awarded to {{candidate_name}}
for scoring {{score_percentage}} on {{test_name}}.
```

Tokens carry the formatting of the text around them — make them bold, color them, change the font size; the substituted value will inherit all of that.

> _📷 Screenshot placeholder: Slide preview before and after token substitution_

## Tips

- **Match casing exactly** — `{{candidate_name}}` works; `{{Candidate_Name}}` does not.
- **Don't break the braces** — If Google Slides reformats `{{` (e.g. into curly typographer quotes), Sashakt won't recognize the token. Paste tokens as plain text.
- **Preview with edge cases** — Test with very long names, very short names, and missing optional values to make sure your layout holds up.

## What if a token has no value?

If a candidate doesn't have a value for a token (e.g. the form didn't ask for _district_), Sashakt replaces the token with an empty string. Plan your design so a missing value doesn't leave an awkward gap (e.g. avoid `from {{district}} district` if district may be empty — use just `{{district}}` on its own line instead).
