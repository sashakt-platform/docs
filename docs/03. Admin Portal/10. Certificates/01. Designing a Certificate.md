# Designing a Certificate

Sashakt issues a personalised certificate to each qualifying candidate. The design itself is **created in Google Slides** — you build the look in a tool your team already knows and then point Sashakt at the slide.

![Create Certificate page](/img/screenshots/certificate-create.png)

The Portal-side configuration is just three fields:

- **Certificate Name** — internal label admins use to identify it
- **Description** — optional, internal note
- **Certificate URL** — the public Google Slides link Sashakt should render
- **Certificate Status** — Active toggle

## The end-to-end workflow

1. **Design your certificate in Google Slides** — logos, layout, signatures, colours, the works.
2. **Add token placeholders** in the slide where candidate-specific values should appear (e.g. `{{candidate_name}}`). See [Tokens & Variables](./tokens-and-variables) for the list.
3. **Share the slide** so Sashakt can read it (_Anyone with the link → Viewer_).
4. **Open Certificates → Create Certificate** in the Portal.
5. **Paste the slide URL** into the **Certificate URL** field.
6. **Attach the certificate** to a test in that test's [configuration](../tests/test-settings#certificate).

When a candidate qualifies, Sashakt makes a copy of your slide, replaces the tokens with the candidate's actual values, and generates a PDF for download.

## Designing in Google Slides

A few tips for a clean result:

- **Page size** — Set the slide to A4 landscape (or whatever size you want the PDF to print at). Go to **File → Page setup → Custom**.
- **Use one slide only** — Sashakt renders the first slide as the certificate.
- **Leave room around tokens** — Long candidate names need space. Test with a name like _"Lakshmi Venkateswara Subramanian"_ to catch overflow.
- **Embed fonts safely** — Stick to the default Google Fonts so the rendered PDF matches what you see in Slides.

## Sharing permissions

Sashakt needs to be able to read the slide. The easiest setting:

- **Share → General access → Anyone with the link → Viewer**

## Updating the design

Edit the Google Slide directly. Changes apply to **future** certificate generations only — certificates that have already been issued aren't regenerated.

:::caution Edits are forward-only
There's no re-issue flow inside the Portal. Plan slide edits accordingly: cosmetic tweaks are safe to make any time, but changes that affect what a certificate _claims_ (organisation name, signature, layout of the candidate's score) won't propagate to previously issued certificates.
:::
