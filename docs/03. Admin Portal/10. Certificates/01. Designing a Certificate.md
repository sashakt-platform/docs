# Designing a Certificate

Sashakt issues a personalized certificate to each qualifying candidate. The design itself is **created in Google Slides** — you build the look in a tool your team already knows, then point Sashakt at the slide.

> _📷 Screenshot placeholder: Certificate configuration screen in the Portal_

## The workflow

1. **Design your certificate in Google Slides** — logos, layout, signatures, colors, the works.
2. **Add token placeholders** in the slide where candidate-specific values should appear (e.g. `{{candidate_name}}`). See [Tokens & Variables](./tokens-and-variables) for the list.
3. **Share the slide** so Sashakt can read it (Anyone with the link → Viewer).
4. **Paste the slide URL** into the certificate configuration in the Portal.
5. **Attach the certificate** to a test in that test's settings.

When a candidate qualifies, Sashakt makes a copy of your slide, replaces the tokens with the candidate's actual values, and generates a PDF.

## Designing in Google Slides

Some tips for a clean result:

- **Page size** — Set the slide to A4 landscape (or whatever size you want the PDF to print at). Go to **File → Page setup → Custom**.
- **Use one slide only** — Sashakt renders the first slide as the certificate.
- **Leave room around tokens** — Long candidate names need space. Test with a name like _"Lakshmi Venkateswara Subramanian"_ to catch overflow.
- **Embed fonts safely** — Stick to the default Google Fonts so the rendered PDF matches what you see in Slides.

## Sharing permissions

Sashakt needs to be able to read the slide. The easiest setting:

- **Share → General access → Anyone with the link → Viewer**

If your organization's policy doesn't allow that, your Sashakt deployment may support sharing the slide directly with a service account email — check with your System Admin.

## Attaching to a test

Once your certificate URL is saved in the Portal, attach it to a test from the test's settings. Sashakt issues a certificate automatically to every candidate who meets that test's passing criteria.

## Updating the design

Edit the Google Slide directly. Changes apply to **future** certificate generations. Certificates that have already been issued don't update automatically — to re-issue with the new design, open the candidate's submission in the Portal and use **Re-issue Certificate**.
