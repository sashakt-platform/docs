# Field Types

When you click **Add Field** in the form builder, Sashakt asks you to pick a field type. Types are grouped into three categories.

![Choose Field Type dialog](/img/screenshots/form-field-types.png)

## Commonly Used

These are the fields almost every registration form needs. Sashakt pre-configures them with the right validation:

| Field | Captures |
|-------|----------|
| **Name** | Candidate's full name |
| **Email** | Email address (with format validation) |
| **Phone number** | Phone number |
| **State** | Pick from the configured state entities |
| **District** | Pick from districts; filtered by the chosen state |
| **Block** | Pick from blocks; filtered by the chosen district |
| **Entity** | Pick any entity (school, institution, etc.) from your [Entity](../entities) hierarchy |

The **State / District / Block** fields are linked — picking a state filters the district list, and so on. That's what keeps the data clean.

## General

For anything else, use these:

- **Short Text** — One-line free text (name variants, ID numbers, codes)
- **Paragraph** — Multi-line free text (addresses, comments)
- **Number** — Numeric input
- **Date** — Date picker

## Choice List

When you want the candidate to pick from a list you control:

- **Check box** — Yes/no or accept-terms single toggle
- **Radio button** — Pick exactly one option, shown as radio buttons
- **Dropdown** — Pick exactly one option, shown as a dropdown
- **Multi Select** — Pick one or more options, shown as a multi-select

For choice fields, you provide the options. Keep option lists short — long lists are painful on mobile.
