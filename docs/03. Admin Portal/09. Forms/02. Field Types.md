# Field Types

Sashakt forms support a rich set of field types — enough to capture almost any kind of registration data.

| Type | Use for |
|------|---------|
| **Text** | Name, ID number, free-form short text |
| **Long text** | Multi-line descriptions, addresses |
| **Number** | Age, score, count |
| **Email** | Email address with validation |
| **Phone** | Phone number with country-code support |
| **Date** | Date of birth, event date |
| **Dropdown** | Pick one from a list (gender, class, language) |
| **Multi-select** | Pick many from a list (interests, languages spoken) |
| **Radio buttons** | Pick one (visually like multiple choice) |
| **Checkbox** | Yes/no, accept terms |
| **Location** | Entity-aware location picker (state → district → block) |

## Text and long text

The workhorses. Use **Text** for anything that fits on one line, **Long text** for paragraphs.

You can set min/max length and a regex pattern (e.g. for ID number formats).

## Number, email, phone

Each has built-in validation. Use these instead of plain text whenever the data has a known shape — it catches typos at form time, not after submission.

## Date

Configurable as a date picker or three dropdowns (day / month / year), which works better on low-end Android browsers.

## Dropdown, multi-select, radio, checkbox

For choice fields, you provide the options. Keep option lists short — long lists are painful on mobile.

## Location

The location field is the standout. Instead of typing a state name, candidates pick from your organization's [entity hierarchy](../entities). Picking _Maharashtra_ filters the next dropdown to Maharashtra's districts only. This keeps responses clean and searchable.
