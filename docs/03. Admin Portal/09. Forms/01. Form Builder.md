# Form Builder

A **form** is the registration screen candidates fill in before they start a test. Use it to capture name, contact, location, school — whatever your program needs to track.

![Form builder](/img/screenshots/form-builder.png)

## Building a form

1. Open **Forms** from the left navigation.
2. Click **Create Form**.
3. Enter a **Form Name** (visible to the candidate) and an optional **Description**.
4. Click **Add Field** to add a field. Sashakt asks you to pick a field type — see [Field Types](./field-types).
5. Configure each field — label, validation, required/optional.
6. Reorder fields with drag-and-drop.
7. Set **Form Status** to Active.
8. Click **Save**.

:::tip Name first
Sashakt won't let you add fields until the form has a name. Enter the Form Name first, then add fields.
:::

## Reusing forms across tests

A form is independent of any one test — you can attach the same form to many tests. This is useful when several tests share the same registration requirements.

To attach a form to a test, open **Test Configuration → Candidate Experience → Candidate Information Form** in the test wizard and pick the form.

## Validating responses

Each field can carry its own validation rules — required, min/max length, numeric ranges, date ranges. Sashakt won't let candidates submit a form until all required fields pass validation.
