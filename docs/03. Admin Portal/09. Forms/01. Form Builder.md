# Form Builder

A **form** is the registration screen candidates fill in before they start a test. Use it to capture name, contact, location, school — whatever your program needs to track.

> _📷 Screenshot placeholder: Form builder canvas_

## Building a form

1. Open **Forms** from the left navigation.
2. Click **Create Form**.
3. Give the form a name (e.g. _Class 8 Math Assessment Registration_).
4. Add fields one at a time, picking from the available [field types](./field-types).
5. Configure each field — label, placeholder, required/optional, validation rules.
6. Reorder fields with drag-and-drop.
7. Click **Save**.

## Reusing forms across tests

A form is independent of any one test — you can attach the same form to many tests. This is useful when several tests share the same registration requirements.

To attach a form to a test, open the test settings and pick the form from the dropdown.

## Conditional fields

For more advanced forms, you can make a field appear only when another field has a specific value. For example:

- Show the _School name_ field only when _Are you a student?_ is _Yes_.

This keeps the form short for everyone and detailed for the candidates who need to see more.

## Validating responses

Each field can carry its own validation rules — required, min/max length, regex pattern, numeric ranges, date ranges. Sashakt won't let candidates submit a form until all required fields pass validation.

## Previewing

Click **Preview** to see exactly what candidates will see. Always preview on both desktop and mobile widths before publishing.
