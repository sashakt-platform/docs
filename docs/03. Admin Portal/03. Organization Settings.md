# Organization Settings

Organization Settings is where System Admins shape how Sashakt looks and behaves for everyone in their organization. Get this right early — many of these choices affect every screen and every test you ship.

> _📷 Screenshot placeholder: Organization Settings landing page_

:::info Who can do this?
Only **System Admins** can edit organization settings.
:::

## Organization shortcode

Every organization has a unique **shortcode** that determines its Portal URL — `https://portal.sashakt.in/<shortcode>`. This is set when the organization is created and usually doesn't change afterwards.

Share your shortcode (or the full Portal URL) with team members so they can log in.

## Feature toggles

Turn major features on or off for your org. Common toggles include:

- **Certificates** — Whether tests can issue certificates
- **OMR mode** — Whether candidates see the OMR (bubble-sheet) option
- **Bulk question upload** — Allow CSV uploads to the question bank
- **Forms** — Use Sashakt's dynamic form builder for registration
- **Analytics export** — Sync submissions to BigQuery

Turning a feature off hides the related menus across the Portal — useful for keeping the interface focused.

## Platform nomenclature

Sashakt lets you rename platform-wide concepts so they match the language your team already uses.

For example, you can change:

- _Test_ → _Assessment_ or _Exam_
- _Question_ → _Item_
- _Candidate_ → _Learner_ or _Participant_
- _Tag_ → _Category_

The change applies everywhere — menus, page titles, the candidate webapp, certificate text. Pick names that will read naturally to both admins and candidates.

## Guides

Surface custom in-app guidance for your team — a link to your internal handbook, a video walkthrough, or a Notion page. Guides appear inside the Portal on relevant screens so new admins don't have to hunt.

## Analytics

Connect external analytics (BigQuery) and configure what gets synced. See the [BigQuery Sync](../integrations/bigquery-sync) integration page for the full setup.
