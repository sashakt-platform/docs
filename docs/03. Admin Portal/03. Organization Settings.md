# Organisation Settings

Organisation Settings is where you set the **defaults** every test in your organisation starts with — and decide which of those defaults test creators are allowed to change.

Open **My Organisation → Organisation Settings** from the left navigation.

![Organisation Settings page](/img/screenshots/organization-settings.png)

:::info Who can do this?
Only **System Admins** can edit organisation settings.
:::

## Fixed vs Flexible — the core idea

Every setting on this page has a **Fixed / Flexible** dial at the top:

- **Fixed** — The value is locked. Every test in the organisation uses this value. Test creators don't see the option.
- **Flexible** — The value here is the default. Test creators can override it on individual tests.

This is how you balance consistency (everyone uses the same scoring scheme) with autonomy (subject-matter experts can build different kinds of tests).

## Test Timings

Defines how long candidates have and when a test is available.

- **Maximum time limit** — In minutes
- **Start time** / **End time** — Daily window during which the test is open

## Questions per Page

How many questions appear on a single page during the test. `1` is the default — one question at a time.

## Marking Scheme

The marks awarded for each question outcome:

- **Correct** — Marks for a right answer (default `1`)
- **Incorrect** — Marks for a wrong answer (default `0`; set negative for negative marking)
- **No Answer** — Marks for an unanswered question (default `0`)

Toggle **Partial Marking** to award marks for partially correct answers on multi-choice and matrix questions.

## Answer Review

Lets candidates see the correct answers for the questions they attempted. The setting controls **when** the review is available — Off by default. Switch it on if you want a learning-focused experience.

## Question Palette

Shows candidates a grid view of every question with status indicators. Helps them track progress and jump around the test.

## Mark for Review

Lets candidates flag questions they want to revisit before submitting.

## OMR Mode

Renders the test as a digital OMR (bubble sheet) instead of one card per question. Good for candidates familiar with paper-based tests and for fast recall-style assessments.

## Pause Test

Allows candidates to pause and resume a test session. Useful in long-form assessments or low-bandwidth contexts where breaks are needed.

## Platform Nomenclature

Renames sections across the platform to match your organisation's language. Switch **Custom** on and you can replace:

- **Dashboard**, **Question Bank**, **Tag Management**
- **Tests** / **Test** (plural and singular)
- **Tags** / **Tag**
- **Test Templates** / **Test Template**
- **Tag Types** / **Tag Type**
- **Forms** / **Form**
- **Certificates** / **Certificate**
- **Entities** / **Entity**
- **Users** / **User**

Leave any field blank to keep the built-in name. The renames apply across the Portal — menus, page titles, buttons.
