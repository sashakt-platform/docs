# Tags

Tags are simple labels you attach to questions and tests to keep your content organized. Once your question bank gets past a few dozen items, tags become essential.

> _📷 Screenshot placeholder: Tags list_

## Tag types

Sashakt groups tags into **types** so they don't blur into one big mess. Typical types include:

- **Subject** — Mathematics, Science, English
- **Class / Grade** — Class 6, Class 8, Class 10
- **Skill** — Communication, Problem Solving, Numeracy
- **Batch / Cohort** — 2024 Spring Batch, October 2025

Each tag belongs to exactly one type. Types are set up by a System Admin and shared across the organization.

## Creating tags

1. Open **Tags** from the left navigation.
2. Click **Add Tag**.
3. Pick a **type** and give the tag a name.
4. Save.

You can now attach this tag to questions in the [Question Bank](./question-bank/creating-questions) and to tests in [Test Settings](./tests/test-settings).

## Filtering by tags

Wherever you see a long list of questions or tests, you'll find a tag filter at the top. Combine tags to narrow down fast — for example, _Subject: Mathematics_ + _Class 8_.
