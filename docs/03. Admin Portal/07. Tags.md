# Tag Management

Tags are labels you attach to questions and tests to keep your content organized. Once your question bank gets past a few dozen items, tags become essential.

![Tag Management](/img/screenshots/tag-management.png)

## Tag types

Sashakt groups tags into **tag types** so they don't blur into one big mess. Typical types include:

- **Subject** — Mathematics, Science, English
- **Class / Grade** — Class 6, Class 8, Class 10
- **Skill** — Communication, Problem Solving, Numeracy
- **Batch / Cohort** — 2024 Spring Batch, October 2025

Each tag belongs to exactly one type. Tag types are managed at the organisation level.

## Creating a tag type and tags

1. Open **Tag Management** from the left navigation.
2. Click **Create Tag Type**.
3. Give it a name.
4. Add tags under that type.

You can also rename the labels "Tag" and "Tag Type" platform-wide via [Organisation Settings → Platform Nomenclature](./organization-settings#platform-nomenclature).

## Filtering by tags

Wherever you see a long list of questions or tests, you'll find a tag filter at the top. Combine tags to narrow down fast — for example, _Subject: Mathematics_ + _Class 8_.

Tag filters also power **Auto Selection** when building tests — Sashakt pulls questions matching the chosen tags into the test pool.
