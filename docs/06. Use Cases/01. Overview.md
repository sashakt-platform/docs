# Use Cases Overview

Sashakt is built for a specific shape of problem — large-scale, multi-region, mixed-language assessments — and shows up in a few recognizable forms across deployments.

This section is a growing collection of the patterns we see. Each one is a sketch you can adapt rather than a step-by-step.

## Skill assessments

Used by training organizations to baseline candidates before a program and measure progress at the end.

**Shape:** Question bank by topic, two tests per candidate (pre/post), certificate on completion. Roles scoped to states or districts so regional coordinators only see their own learners.

## Certification exams

Used to award credentials — language proficiency, vocational skills, professional development.

**Shape:** High-stakes test settings (random question selection from a pool, shuffled options, no feedback to candidate). Personalized certificates generated from a Google Slides template. BigQuery sync for institutional reporting.

## Surveys and assessments

Used by research and evaluation teams.

**Shape:** Form-heavy registration (demographics), shorter tests with subjective items, no certificate, results exported for analysis. Often run across many states with State Admins managing their own data.

## Field data collection

Used by program teams to capture structured data from field workers — not exactly "tests" but the same form + submission flow.

**Shape:** Long forms with many entity-based dropdowns (state → district → block → village). Multi-language support for the language workers are comfortable in. Submissions analyzed in Looker Studio via BigQuery sync.
